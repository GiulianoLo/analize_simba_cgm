# Restructure step 3: what moved where

Step 3 of the restructure (October 2026) moved the functions the notebooks had defined in their own
cells into `simbanator`. This file records every case where the library version is not a one-to-one
copy of a notebook function: merges, renames, behaviour changes, and functions that stayed in their
notebook. The notebooks themselves switch to these imports in step 5.

Every lifted function was run side by side with its notebook original on the same inputs (1,008
checks); the differences that remain are listed below and are deliberate.

## io (tables, catalogs, products, qc)
- `_s`, `_as_str` -> one explicit `io.tables.as_str` (raises on undecodable bytes) + `read_table` decodes all byte columns at read time (user note).
- `read_catalog_props`, `_read_hist`, `read_anchor`, `read_cat`, `_read_halo_cat`, `_ms_at`, `_gal_field`, `_gfield`, `_read_cat` -> general `read_galaxy_columns` / `dataset` / `parent_halo_columns` / `sim_attributes`.
- `cat_path`, `caesar_file`, `sim_prefix` -> `catalog_path`, `file_prefix` (from the config).
- `by_snap_gal`, `row0_arr` -> `align_to_rows`; `_keys` -> `galaxy_keys`; `_col` -> `float_column`; `_frame` -> `products.read_frame`; `load_selection` -> `products.read_selection`; `_tagged` -> `tagged_path`; `_ztag` -> `z_tag`; `_nearest_snap`, `nearest_snap` -> `nearest_snapshot`; `_t_to_z`, `_z_to_t` -> `time_redshift_maps`; `eps_pkpc` -> `softening_pkpc`; `_hdf5_status` -> `qc.hdf5_status`.
